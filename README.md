WAR FIELD ZONE — realistic-style FPS prototype.
Includes atmospheric military arena, ground texture details, buildings, trees, first-person M4/Sniper weapon silhouettes, recoil and muzzle flash, bots, score, HP, 10-minute match and repeated 3-minute overtime.

Build APK: upload all files to GitHub repository root on main; Actions > Build Android APK > Run workflow; download artifact war-field-zone-debug-apk after success.
Important: still a canvas-based FPS-style prototype, not a full 3D engine with true 3D models/materials. Test on device; no online multiplayer yet.
